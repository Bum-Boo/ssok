# 제품과 개발 정책

갱신: 2026-09-30. 사용자 결정과 기존 개발 규칙을 요약해요. 구현 상태는 [STATUS](STATUS.md), 구조 결정은 [ADR 색인](adr/INDEX.md), 코드에 대한 설명은 [DATA_MODEL](DATA_MODEL.md)과 [FLOWS](FLOWS.md)를 따르세요.

## 학습과 과제

- 첫 경험은 초등 고학년 기준이에요. 튜토리얼 강제 이수 없이 코드와 자유 조립에 접근해요.
- 중심은 사용자가 자기 조합으로 해결하는 Stage와 자유 제작 Lab이에요. 15개 과정은 계획이며 모든 과정이 구현된 상태가 아니에요.
- 깃발은 첫 경험 후보예요. 이족·Kit의 추가 보행 연구는 보류하고 기존 실험을 전시해요.
- 성공은 실제 관측으로 판단해요. 목표 명령, AI 완료 문장이나 화면 연출로 성공을 대체하지 않아요.
- 관찰, 설계 가설, 구현, 해당 소스의 검증과 출시는 구분해서 기록해요. 도움 사용과 학습 효과의 해석은 연구 설계 때 별도로 정해요.

## 저장과 제어

- 편집 조립의 정본은 ConnectionGraph예요. 전기 배선은 위치를 보존해요.
- 지원하지 않는 코드와 충돌한 블록 초안은 조용히 버리지 않아요. 가져오기는 검증 뒤 작업을 교체하고 코드를 자동 실행하지 않아요.
- 한 로봇의 명령 제어권은 하나예요. Stop과 모드 변경은 이전 실행의 늦은 명령을 무효화해요. Stop의 자세·그립 유지 의미는 제어기별로 명시해요.

## AI와 공유 기능

- AI 연결은 선택형이에요. 기존 외부 실험 브리지/MCP와 앱 내 자연어 과제 수행은 별도 기능이에요.
- 자연어 수행을 추가할 때 현재 장면 대상, 지원 행동, 실행 한도와 실제 결과를 검사해요. 생성된 임의 코드·셸 명령을 실행 계약으로 사용하지 않아요.
- 제공자·모델·인증/과금 방식, 전송 데이터와 호출 한도를 첫 요청 전에 알리고 이미 확인한 범위를 재사용해요. 유료 경로로 조용히 전환하거나 자동 재시도하지 않아요.
- 인증·요금 정책은 연결 구현이나 출시 때 공식 문서로 다시 확인해요. 날짜 있는 과거 조사로 현재 가격을 보장하지 않아요.
- 자격증명은 앱, 프로젝트 JSON, 저장소 문서와 인계에 넣지 않아요. 공유 서버, 계정과 리믹스는 후속이에요. 권한·연령 정책이 확정되면 별도 계약과 검증을 추가해요.

## 화면과 번역

- 피드백은 실제 연결이나 관측과 연결하고 다음 행동을 알려줘요. 확인하지 못한 실패 원인을 지어내지 않아요.
- 사용자 문구가 바뀌면 영어, 한국어, 중국어 간체와 일본어를 같은 변경으로 갱신해요. 새 문자열은 기존 번역 검사만 믿지 말고 카탈로그 포함 여부도 확인해요.
- UI 작업은 가능한 실제 전후 화면과 언어별 잘림·글리프 검사를 남겨요. 문서만 바뀌면 번역 영향 없음과 앱 검사 미실행을 명시해요.

장문의 놀이/자연어 조사 노트가 작업 브랜치에 있으면 해당 요구의 원문·근거를 추가로 읽어요. 이 요약은 날짜 있는 조사를 대체하지 않으며 새로운 provider 정책이나 교육 효과를 주장하지 않아요.
