# 설정·테마·언어

갱신: 2026-09-30. 사용자 승인에 따라 issue #38에서 구현했어요. 결정 경계는 [ADR 0026](adr/0026-interface-preferences.md)를 따르세요.

## 사용법

상단 톱니바퀴로 설정을 열어요. 설정을 바꾸면 바로 적용하며 로봇, 배선, 학습자 코드와 미적용 블록 초안은 유지해요. 실행 중인 코드도 계속 실행돼요. 설정 창에서는 로봇 수동 입력과 카메라 조작을 멈춰요. Esc나 닫기 버튼으로 닫으면 톱니바퀴에 포커스를 돌려줘요. 로봇 키 조작은 3D 공간을 클릭한 뒤 사용해요.

| 항목 | 지원 | 저장 |
|---|---|---|
| 언어 | 한국어, 简体中文, 日本語, English | 기존 `user://language.cfg` |
| 테마 | 시스템 설정, 밝게, 어둡게 | `user://interface.cfg` |
| 화면 글자 | 100%, 115%, 130%, 150%, 200% | `text_scale` |
| 코드 글자 | 같은 배율을 독립적으로 선택 | `code_scale` |
| 효과음 | 음소거, 0–100% 음량 | `muted`, `volume` |

기본값은 시스템 테마, 글자 100%, 효과음 켜짐/60%예요. 테마 자동 감지가 지원되지 않는 네이티브 환경은 기존 다크 외관을 사용해요. 지원 플랫폼에서는 Godot 시스템 변경 콜백을 사용하고, 웹에서는 `prefers-color-scheme`을 1초마다 확인해요. 사용자가 밝게/어둡게를 고르면 시스템 변경으로 덮어쓰지 않아요.

기본 설정으로 되돌리기는 테마, 글자와 효과음만 초기화하고 선택 언어와 프로젝트는 보존해요. 저장 실패 시 현재 설정은 적용한 상태로 유지하고 저장 권한 확인 안내를 표시해요. 기기마다 로컬 저장하며 브라우저 데이터를 지우면 선호도 사라져요. 계정 동기화나 프로젝트 내 개인 선호 저장은 구현하지 않았어요.

중국어는 간체만 지원해요. OS의 중국어 지역 표시는 기존 정책에 따라 `zh_CN`으로 정규화해요. 번체 번역 지원을 주장하지 않아요. [번역 규칙](LOCALIZATION.md)을 함께 읽어요.

## 코드 진입점과 변경 규칙

- `src/ui/interface_preferences.gd`: Preferences autoload. 저장값은 허용 키·타입·범위를 확인하고 손상된 항목은 기본값으로 복구해요.
- `src/ui/settings_panel.gd`: 스크롤 가능한 설정 창, 즉시 적용/저장 결과, 언어 선택과 포커스 복원.
- `src/ui/ssok_theme.gd`: 의미별 팔레트, 글꼴 배율, 구문 색상과 공유 Theme. 밝은 테마는 별도 팔레트예요. 새 Theme를 만든 뒤 기존 리소스에 한 번 병합해 모든 창이 함께 갱신돼요.
- `scenes/main.gd`: 설정 입구, 모달 입력 경계, 반응형 상단과 임무/시작 카드 위치. 좁거나 낮은 창에서는 중복 시작 카드를 숨기고 임무의 시작 행동을 유지해요.
- `src/ui/flag_mission.gd`: 기존 선택/연결/성공 효과음의 음량과 즉시 음소거. 물리 성공 판정과 시각 피드백은 소리와 독립적이에요.

UI 글자 크기 override는 `SsokTheme.font_size(base)`로 만들어요. 기존 override의 원본 배율과 팔레트 역할은 `remember`/`adapt`로 보존해 반복 전환 때 확대가 누적되지 않아요. 코드 글자 크기는 UI 배율을 곱하지 않아요. 3D 재질이나 물리는 테마 변경 대상이 아니에요.

언어를 바꿀 때 블록 카드를 다시 생성하지 않아요. 일반 블록 제목은 번역 원문을 유지하고 raw 코드 블록 안내는 원문·인수를 바인딩해 입력/선택/초안을 보존해요. 학습자 변수와 코드 문자열은 번역하지 않아요. 문자열 변경은 `tools/localization/settings_messages.json`과 세 PO를 같은 변경에 갱신해요.

## 검증과 증거 갱신

`tests/interface_preferences_check.gd`는 저장/손상값/실패 경로, 키보드 Esc/포커스, 원문 갱신, 초안/그래프/탭/모드/실행 VM 보존, 두 테마의 대비, 독립 글자 배율, 확대 창 위치와 음소거를 확인해요. `-- --screenshots`를 붙인 네이티브 실행은 `user://settings_previews/`에 실제 화면을 남겨요.

Web 검사는 `tools/ci/browser_settings.py`와 export의 실제 좌표를 사용해요. 테스트 전용 `?ssok_verify=1`에서 제공하는 인터페이스 관측에는 값과 해시만 포함하고 학습자 원문·개인 프로젝트·토큰은 추가하지 않아요.

UI 변경 시 4개 언어, 두 테마, 확대/좁은 창의 실제 화면과 관련 회귀·Web/Linux 빌드를 함께 확인해요. 새로운 결과는 [이번 구현 증거](evidence/settings_implementation_2026-09-30/README.md)에 소스 커밋·환경·명령·미검증 범위와 함께 기록해요. 과거 감사 결과는 당시 소스의 증거로 보존해요. 스크린리더·모든 OS의 자동 외관·모든 창 크기까지 검증한 것으로 확대 해석하지 않아요.

구현 API는 [Godot DisplayServer](https://docs.godotengine.org/en/stable/classes/class_displayserver.html), [Theme](https://docs.godotengine.org/en/stable/classes/class_theme.html)를 확인했어요(2026-09-30). 웹 대비 평가와 네이티브 토큰 평가를 구분해요.

기존 [설정 UX 감사](SETTINGS_UX_AUDIT_2026-09-30.md)는 구현 전 상태의 증거예요. 이 구현은 최신 main의 문서 체계와 Stage 계약을 함께 유지해요.
