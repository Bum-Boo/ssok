# 0006 — Project name "ssok", private repo, commit identity

- Status: accepted; private-only incubation is superseded for the reviewed product release by [0013](0013-reviewed-product-publication.md). Name and commit identity remain accepted.
- Date: 2026-09-10

## Context

Needed a repo name and initial visibility/identity before any code could be pushed.

## Decision

- Name: **ssok** (쏙) — the sound/feel of a part snapping into place, matching the core UX
  ("bring it near the spot and it clicks in"). Rejected: `boltbyte` (mechanical+code duality, less
  distinctive), `sangja` (too tied to "과학상자", awkward internationally), `robolab` (already a
  LEGO product name).
- Repo `Bum-Boo/ssok`, **private** — commercial intent, not yet ready for public visibility.
- Commit identity: `Bum-Boo` / the account's public GitHub email.

## Consequences

- Revisit repo visibility (public/private) and license as a separate, explicit decision — not
  implied by this one.
