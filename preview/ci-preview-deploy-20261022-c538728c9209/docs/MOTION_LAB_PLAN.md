# GPT motion lab 구현 계획 — 2026-09-15

목표: 사용자가 목표를 적으면 `gpt-5.6-luna`가 현재 관절 프로그램의 파라미터를
제안하고, ssok 물리 시뮬레이션으로 비교·수정한 결과를 WASD 동작에 적용한다.
이번 단계는 **피드백 기반 파라미터 탐색**이며 모델 가중치 학습/RL이 아니다.

1. 공식 모델/API 문서와 로봇 LLM 연구·Godot/MCP 구현을 조사한다.
2. 그래프 스냅샷·4개 파라미터 검증·격리된 물리 평가기를 만든다.
3. 키를 서버에만 두는 Responses API 브리지와 비용 없는 mock provider를 만든다.
4. 기준 동작 → 후보 → 실제 평가 → 피드백 → 최고 결과 유지 루프를 연결한다.
5. Godot에서 시작/진행/취소/명시적 적용/저장을 지원하고 MCP 도구를 제공한다.
6. 악성·범위 초과 입력, 취소, 기존 조작 회귀, 실제 물리 및 mock 통합을 검증한다.

## 완료 기준

- 요청한 모델명을 유지하며 키가 Godot/브라우저/소스에 들어가지 않는다.
- 임의 코드·명령·파일 경로 대신 엄격한 수치 정책만 실행한다.
- 그래프의 실제 배선으로 관절을 찾고 매 평가를 새 물리 상태에서 시작한다.
- 동일한 기준 평가, 이동/드리프트/자세/넘어짐 지표, 결과 이력을 볼 수 있다.
- 탐색 횟수와 실제 API 호출 수가 제한되며 실패·거절·취소가 숨겨지지 않는다.
- 사용자가 확인하기 전에는 현재 동작/코드/조립품을 덮어쓰지 않는다.
- 로컬 API 키가 없으면 실제 GPT 테스트 미실시를 명시한다.
