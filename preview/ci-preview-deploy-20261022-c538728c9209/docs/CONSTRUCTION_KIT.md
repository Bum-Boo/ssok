# 기본 부품부터 조립하는 ssok 키트

> **모터 토크 수정 (2026-09-22):** [ADR 0020](adr/0020-whole-step-actuator-torque-budget.md)은 물리 스텝 전체의 모터 예산을 제한한다. 집기는 수정된 모델에서 다시 검증했다. 아래 과거 측정 기록은 이전 per-pass 구현의 결과로 구분하며, 현재 토크 한도에서의 성공 근거로 사용하지 않는다.

수정된 토크 한계에서 기본 상승 시간을 4초로 설정하고 집기 관련 12개 검사 묶음을 통과했다. 원래 실패했던 상자 위치 조건과 277개 물리 검사를 포함한다. [수정 후 집기 검증](evidence/torque_budget_2026-09-22/pickup_revalidation/README.md). 지속 보행은 아직 완료되지 않았다.

2026-09-15. 이전의 `ssok_modular_humanoid.blend`는 몸통·팔다리 하위 조립품을 한 메쉬로
묶은 휴머노이드 전용 프리팹이었다. 오브젝트가 37개라는 이유만으로 과학상자식 모듈화라고
설명한 것은 잘못이었다. 새 키트는 구조 부품과 실제 조립 위치부터 다시 정의한다.

## 무엇이 달라졌나

- 빔, 판, 꺾쇠, U 브래킷, 스페이서, 축 커플러, 볼트, 너트, 접촉 패드가 별도 부품이다.
- 몸통·팔·다리라는 카탈로그 부품은 없다. 기본 부품을 연결한 결과가 그 구조가 된다.
- 빔과 판의 체결 구멍은 20 mm 간격이다. 4 mm 체결 구멍과 8 mm 축 인터페이스를 구분한다.
- 각 구멍 양면의 위치·법선·호환 태그가 실제 Godot 조립 포트다. 구멍 장식만 추가한 것이 아니다.
- 모터와 컨트롤러는 완제품 단위다. 구조용 레일·연결판·외장을 하나의 팔다리 메쉬로 합치지 않는다.
- 동일한 부품 카탈로그로 휴머노이드와 다리 구조물을 조립한다. Blender 장면도 해당
  `ConnectionGraph`를 내보낸 자료에서 생성하며 별도의 로봇 배치를 수작업으로 복제하지 않는다.

현재 예제는 로봇 181개 부품과 상자 1개(208연결), 다리 구조물 29개 부품(28연결)이다.
로봇 부품 수에는 개별 볼트·너트가 포함된다. 현재 카탈로그는 16채널 컨트롤러를 포함한 25종이며
동일 제품을 반복 사용한다. 추가 컨트롤러의 존재가 보행 성공을 의미하지는 않는다.

이는 **ssok 자체 가상 규격**이며 상용 과학상자, LEGO, 실제 나사 규격이나 특정 모터와의
호환성을 인증하지 않는다. 볼트 연결은 교육용 고정 결합이며 나사산 마찰/체결 토크를 계산하지 않는다.

## 실행과 편집

```sh
godot --path . --language ko --script tools/godot/play_construction_kit.gd
blender --disable-autoexec assets/blender/ssok_construction_kit_verified.blend
```

앱에서 조립 키트 휴머노이드 또는 키트 다리 예제를 고른다. 부품 필터는 새 키트의 기본 부품만
보이도록 전환된다. 각 빔이나 판을 선택해서 G/R로 이동·회전하고, 맞는 체결 구멍에 스냅한다.
다른 구멍도 조립 위치로 사용할 수 있다. Ctrl+Z는 부품 위치와 연결을 함께 복구한다.
평소에는 실제 관통 구멍이 보이며, 부품을 선택하거나 이동할 때 노란 연결점 안내가 표시된다.
기존 예제·구형 카탈로그는 이전 저장 시나리오 호환성을 위해 유지한다.

최종 Blender 원본은 **새 파일** `ssok_construction_kit_verified.blend`다. 먼저 열었던
`ssok_construction_kit.blend`는 중간 미리보기로 보존하며, 다리 지지점의 최종 수정은 verified 파일에 있다.
이전 파일과 사용자의 열린 편집
세션을 덮어쓰지 않는다. 부품 트레이·조립 예제·분해도를 통해 기본 부품과 결합 위치를 확인한다.
동일한 제품 번호의 여러 인스턴스는 메쉬 데이터를 공유하지만 위치·회전은 별개 오브젝트다.
공유 메쉬의 형태를 편집하면 같은 제품 인스턴스에 반영되는 것은 의도된 카탈로그 동작이다.

## 구현의 정본

- `assets/construction_kit/catalog.json`: 치수, 재질, 구멍, 포트, 질량, 충돌 정의.
- `tools/blender/make_construction_kit.py`: 실제 구멍이 있는 메쉬와 Blender 장면 생성.
- `tools/godot/make_construction_kit_defs.gd`: 동일 카탈로그에서 `PartDef`와 PBR 메쉬 생성.
- `presets/construction_kit_humanoid.gd`: 같은 기본 부품을 사용하는 두 조립 그래프와 배선 코드.
- `assets/construction_kit/assemblies.json`: 실제 그래프를 Blender에 전달하는 오프라인 자료.
- `src/runtime/kit_humanoid_motion.gd`: 실제 고정 연결 묶음·회전 조인트·배선·기하에서 관절 역할 해석.

실행 중에는 고정 연결 부품끼리만 하나의 솔버 강체로 묶을 수 있다. 편집 그래프의 부품을
합치거나 지우는 작업이 아니며, 각 부품의 메쉬·충돌 위치·질량·배선은 보존한다.
로컬 스냅샷은 256부품·1024연결로 제한한다. 집기 브리지에는 여전히 그래프 식별자와 제한된
정책·측정값만 보내며, 더 많은 부품이 GPT 호출 수를 늘리지 않는다.

## 검증 기준

1. Blender에서 구조 부품마다 별도 오브젝트로 선택할 수 있는가.
2. 렌더된 체결 구멍과 조립 포트의 중심·축·표면이 일치하는가.
3. 같은 빔의 서로 다른 구멍에 실제로 스냅할 수 있는가.
4. 휴머노이드와 다른 구조물이 동일한 부품 ID를 재사용하는가.
5. 실행 모드에서 고정 묶음의 질량·기하·배선이 보존되는가.
6. 조립 부품 하나의 이동/Undo 및 한·중·일 UI가 작동하는가.

기존 프리팹의 걷기/집기 성공 수치를 새 구조의 성공으로 가져오지 않는다. 새 구조의 동작은
독립적으로 검증해야 한다. 달리기·실물 전이·실물 나사 체결이나 제조 가능성 인증은 제공하지 않는다.
내장 휴머노이드 제어기는 예제의 10관절 구조와 다리 240 mm·팔 220 mm 축 간격을 지원한다.
임의 형태로 재조립한 로봇까지 자동으로 조종하는 범용 제어기는 아니며, 다른 구조에는 맞는 관절 코드가 필요하다.

## 원본에서 재생성

아래 Blender 명령은 새 키트의 생성 파일을 다시 저장한다. 해당 파일에서 직접 편집한 내용이
있다면 먼저 다른 이름으로 보관한다. 이전 `ssok_modular_humanoid.blend`는 대상이 아니다.

```sh
blender --background --python-exit-code 1 --python tools/blender/make_construction_kit.py -- --blend assets/blender/ssok_construction_kit_verified.blend
godot --headless --path . --editor --import --quit
godot --headless --path . --script tools/godot/make_construction_kit_defs.gd
godot --headless --path . --script tools/godot/export_construction_kit.gd
blender --background --python-exit-code 1 --python tools/blender/make_construction_kit.py -- --reuse-source --blend assets/blender/ssok_construction_kit_verified.blend
blender --background assets/blender/ssok_construction_kit_verified.blend --python-exit-code 1 --python tools/blender/check_construction_kit.py
```

Godot 리소스를 다시 생성한 뒤 최종 그래프를 내보내 Blender 장면을 재구성하는 순서다.
`--reuse-source`는 이미 검증된 낱개 메쉬를 재사용하고 조립 장면만 다시 만든다.

한·중·일 번역은 현재 부품 25종, 키트 필터·예제 버튼, 로드 안내와 튜토리얼을 함께 유지한다.
기존 집기 탐색의 유료 동의·취소·실행 여부 불명·저장 후 재검증 경계는 변경하지 않는다.
설계 변경은 [ADR 0011](adr/0011-elementary-construction-kit.md)에 기록했다.

## 초기 모듈화 검증 기록

아래는 초기 구현 당시의 검사 수와 결과다. 모터 동작을 포함한 과거 결과는 토크 수정 후의
검증과 구분한다. 현재 전체 검사 결과는 [수정된 모델의 검증 기록](evidence/bounded_feedback_2026-09-22/README.md)에 있다.

- 구조 검사 12,254개 / 실패 0: 실제 관통 구멍 197개와 양면 포트, 12가지 다른 구멍 스냅,
  구조재 겹침 없음, 다른 구조물의 부품 재사용, 실제 그래프의 질량·메쉬·배선 보존.
- 다리 구조물은 하부 고무 패드 4개를 실제 부품으로 체결했다. 3초 중력 안정화에서
  수직도 최솟값 1.000, 상판 높이 약 0.183 m를 측정했다. 숨은 바닥이나 강체 고정은 사용하지 않았다.
- 새 키트 작업실 GL Compatibility 화면 검사 389개 / 실패 0: 한·중·일, 1152×648 작은 창,
  빔 하나의 G 이동과 Undo, 선택 시 연결점 표시, 두 예제와 새 튜토리얼.
- 언어팩 30,321개, 기존 작업실 376개, 9단계 튜토리얼 486개, 보행 실험 코어 232개 검사 통과.
- 기존 스냅·Blender식 편집(54개)·실행 물리·수동/코드 전환·상대각 코드(26개) 회귀 검사 통과.
  구형 휴머노이드의 집기도 435개 검사에서 통과했으나 이는 새 구조의 집기 결과가 아니다.
- 새 182부품 그래프의 실제 실패 결과 저장·로드 207개 검사 통과. 약 42 KB로 기존 256 KiB
  한도 안에 들어가며, 그래프 식별자와 각 부품 위치는 정확히 보존한다. 테스트 기록만 제거했다.
- 기존 집기 정책/실행/완료 정지 415개 및 구형 모듈 네 월드 병렬 실험 34개 검사 통과.
  도달각 함수 분리 중 발견한 float32 반올림 회귀는 64-bit 각도 보존으로 수정 후 재검증했다.
- 최종 Blender 읽기 전용 검사에서 로봇 181개·다리 29개 오브젝트의 모든 변환과
  공통 메쉬 참조가 실제 그래프와 일치함을 확인했다. 원본 메쉬는 외부 파일 링크 없이 포함한다.
- Godot 최종 import·기본 장면 로드와 `git diff --check` 통과.

새 구조의 집기 성능 검증은 위 모듈 조립 검사와 별개다. 실제 유료 GPT 호출, 웹 내보내기,
실물 게임패드·로봇·나사 체결은 이번 검증에 포함하지 않았다.

## 수정된 토크 모델의 집기 검증 (2026-09-22)

현재 기본 상승 시간은 4초다. 실제 양손 접촉, 25 cm 이상 상승, 1초 유지, 자세 안정성과
놓은 뒤 중력 낙하를 확인하는 277개 물리 검사와 집기 관련 12개 검사 묶음이 통과했다.
실패했던 상자 위치 조건과 그래프 순서 반전도 포함한다. 기간별 실패 비교를 포함한 전체 기록은
[집기 재검증](evidence/torque_budget_2026-09-22/pickup_revalidation/README.md)에 보존했다.
현재 [실제 녹화](media/PICKUP.md)는 약 47.7 cm 상승과 1초 유지를 측정했다. 지속 보행은 미완료다.

### 토크 수정 전 집기와 보행 기록 (2026-09-22)

이하 275개 검사, 거리와 자세 값은 이전 per-pass 액추에이터로 얻은 이력이다.
위의 수정 후 결과와 합산하거나 현재 토크 한도의 검증으로 사용하지 않는다.

새 부품의 어깨·팔꿈치 축과 고무 패드 중심을 사용해 팔 도달각을 계산한다. 들어 올릴 때
접촉 순간의 실제 관절각에서 유지 자세까지 부드럽게 이동하고, 로봇 전체의 질량 중심과
속도, 잡은 상자의 질량을 발 지지 위치와 비교해 발목 모터 목표각을 보정한다.
몸통의 수직도만 보는 이전 제어는 앞으로 이동한 팔과 상자의 무게를 감지하지 못했다.

- `construction_kit_motion_check.gd`: **275개 검사 / 실패 0**. 기본 단일 실험의 최대 상승
  **47.8 cm**, 연속 유지 **1.0초**, 수직도 최솟값 **0.994**. 두 독립 월드도 각각 성공했다.
- 상자 시작 위치를 좌우 **±5 mm**, 앞뒤 **±10 mm** 옮긴 네 모서리와 부품·연결 순서를
  뒤집은 그래프에서도 같은 접촉·25 cm 상승·1초 유지·수직도 기준을 통과했다.
- 개인 Himmel의 독립 실행에서 9개 위치 조합, 순서 반전, 반복 두 회를 포함한
  **12회 모두 성공**했다. 최대 상승 47.6–47.9 cm, 수직도 최솟값 0.989–0.996이었다.
- 양손의 실제 접촉 이전에는 임시 집기 구속을 만들지 않는다. 놓은 상자의 중력 낙하,
  각도·토크 제한, 그래프 불변성, 리셋, 독립 실험 월드 해제가 같은 검사에 포함된다.
- 당시 부품·질량·충돌 모양·중력·35 Nm 다리 및 12 Nm 팔 모터 명목 설정·성공 기준을 바꾸지 않았다.
  이 명목 설정이 물리 스텝 전체의 토크를 제한하지 못하던 결함은 이후 ADR 0020에서 수정했다.
  몸통에 외부 이동 힘을 더하거나 물체 위치를 직접 바꾸지 않는다.

토크 수정 전 평평한 바닥의 기본 보행은 **발을 주로 끌며 이동하는 느린 동작**이었다. 당시 12초 탐색
