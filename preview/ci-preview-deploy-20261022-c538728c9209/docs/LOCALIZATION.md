# 인터페이스 언어

## 지속 갱신 규칙

사용자 지시(2026-09-15): **앞으로 모든 업데이트에서 언어팩 영향도 함께 확인한다.**
화면 문구를 추가·수정·삭제하면 영어 원문과 한국어·중국어 간체·일본어 번역을
같은 변경에 반영한다. 번역을 후속 작업으로 미루지 않는다.
부품명·도움말·툴팁·오류·AI 실험실의 안전/비용 경고도 포함한다.

완료 전에 새 문구의 세 언어 카탈로그 등록 여부, 자리표시자 일치, 실제 화면의
글자 깨짐·잘림을 확인하고 아래 검증 명령을 실행한다. 카탈로그 간 항목 수가 같다는
것만으로 새 UI 문구의 번역 누락이 없다고 판단하지 않는다.
UI나 문구가 바뀌지 않은 업데이트는 번역 수정이 불필요했음을 결과에 명시한다.
이 규칙은 프로젝트 `AGENTS.md`의 필수 작업/완료 기준에도 기록되어 있다.

모듈형 휴머노이드/집기 탐색에서도 18종 부품 이름, 실험 단계/출처/오류, 병렬·취소·비용 경고,
시나리오 저장/재실행, 집기 튜토리얼을 세 언어에 함께 반영했다. 해당 추가 문구 목록은
`tools/localization/pickup_messages.json`이며 PO가 번역 정본이다. 완료된 물리 평가의
실험 화면과 저장/연결 탭은 `tests/pickup_lab_ui_check.gd -- --screenshots`로 확인한다.

기본 부품 조립 키트는 24종 부품명·두 예제 버튼·필터·상태 안내와 새 첫 튜토리얼을 포함해
33개 영어 문구, 99개 번역을 함께 추가했다. 튜토리얼은 총 9단계다. 추가 문구 목록은
`tools/localization/construction_messages.json`이며 `tests/localization_check.gd`가 세 언어의
명시적 원문 커버리지를 검사한다. 새 작업실·다리·튜토리얼과 1152×648 화면은
`tests/construction_kit_ui_check.gd -- --screenshots`로 확인한다.

## 사용법과 구현

상단 작업 표시줄 오른쪽에서 **한국어 / 简体中文 / 日本語 / English**를 선택한다.
톱니바퀴의 [설정 창](INTERFACE_PREFERENCES.md)에서도 선택하며 언어 전환 후 선택기에 포커스를 유지한다. 이미 만들어진 블록 제목과 raw 코드 블록 안내도 갱신하고 미적용 초안을 보존한다.
중국어는 간체이며 번체는 아직 별도 지원하지 않는다.
최초 실행은 OS 언어(ko/zh/ja, 그 외 영어)를 따르고, 선택한 언어는
`user://language.cfg`에 저장한다. `--language ko` 등 실행 인자는 저장값보다
우선하며 저장값을 바꾸지 않는다.

- 부품 목록, 편집/실행 조작 안내, 튜토리얼의 모든 단계, 상태 메시지, AI 실험실과 결제·취소 경고를 번역한다.
- 언어 전환으로 조립, 학습자 코드, 목표 입력, 연결 토큰, 동작 파라미터를 초기화하지 않는다.
- 모델 응답/원격 서비스가 보내는 자유 형식 오류, 코드 문법, 보드 핀/JSON 키는 번역하지 않는다.
- 기본 AI 목표는 창을 만들 때 번역한다. 이후에는 사용자 입력으로 취급하여 그대로 유지한다.
- CJK 글꼴과 지역별 한자 자형, 코드용 고정폭 글꼴을 포함한다. 웹 내보내기 실기기는 별도 검증 대상이다.

번역 정본은 `assets/locales/{ko,zh_CN,ja}.po`다. 영어 원문을 msgid로 사용하고
Godot TranslationServer의 자동 번역을 사용한다. 변수 포함 문장은 반드시
번역 후 포맷하며, 갱신이 필요한 Label에는 `SsokLocale.bind()`로 원문과 인자를
보존한다. 사용자 데이터 인자는 기본적으로 번역하지 않으며, 부품명 등만 명시적으로 지정한다.
프로토콜의 ID·키·상태 enum을 번역된 문자열로 교체해서는 안 된다.

검증: `godot --headless --path . --language en --script tests/localization_check.gd`.
화면 확인: 같은 명령에서 `--headless`를 빼고 `-- --screenshots`를 추가하면
`user://localization_previews/`에 언어별 작업실/실험실 이미지를 저장한다.
