# Engine notices

`Godot-LICENSE.txt` and `Godot-COPYRIGHT.txt` are unmodified files downloaded from
`https://raw.githubusercontent.com/godotengine/godot/4.7.2-stable/` on 2026-09-22.
They accompany both Linux and Web exports. Keep them aligned with the pinned engine;
an engine migration must refresh these notices as well as the build archive checksums.
